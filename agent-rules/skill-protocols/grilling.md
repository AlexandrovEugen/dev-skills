# Grilling protocol

Use this file only with an invoked grilling skill.

- Build the design tree from the dev's decisions and checked facts.
- Settle a branch when the dev's words, a prior decision, or a checked fact derives its answer.
- Record a derived answer in the design tree and do not ask the dev to approve it.
- Look up every fact a question needs before asking the dev; a question asks for a decision, never a fact.
- Ask the complete frontier of decisions that only the dev can make.
- Leave a question that depends on another open question for a later round.
- Restate each open question with its options and recommendation in every round.
- Before claiming system behavior, read executable code and the tests that exercise it; use comments only as evidence of intent.
