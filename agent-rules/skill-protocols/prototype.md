# prototype

1. The prototype answers one named question, on the branch the skill picks: logic or UI.
2. It is marked throwaway, starts from one command, and shows its state after each action.
3. The stage's protocols stay in force while it is built.

**Ends when** the prototype runs and its answer is captured as the skill says. The stage goes on at the step it left.
